# COMET 시작하기

COMET은 촉매의 조성, 담체, 제조 단계와 가격 자료를 바탕으로 제조 원가를
추정하는 도구입니다. Windows 앱이나 웹 화면에서 같은 계산 기능을 사용합니다.
실험 결과나 공급사 견적을 대신하는 값이 아니라, 연구 초기의 조성·제조법
비교에 쓰는 추정치입니다.

화면 왼쪽의 **언어**에서 한국어를, **표시 단위**에서 kg 또는 lb를 선택합니다.
금속 기호와 단위는 그대로 표시합니다. 문헌 요약, 계산 모델의 경고문,
출처 메모 등 자료에 포함된 문장은 원문을 유지합니다.

## 열촉매 원가 계산

1. **원가 계산**에서 **열촉매**를 선택합니다.
2. 활성 금속과 담체를 지정합니다. 필요하면 조촉매와 담체를 추가하고,
   전체 질량 비율이 맞는지 확인합니다. 라이브러리 재료를 고르면 저장된
   단가와 출처가 연결됩니다. 직접 입력한 가격은 직접 입력값으로 표시됩니다.
3. **제조법**에서 제조 경로 카드를 선택합니다. 카드의 가공비는 재료비를
   제외한 값입니다. 생산 규모를 바꾸면 해당 규모에 맞는 장비로 제조
   단계가 바뀝니다. 동일한 장비를 여러 번 쓰는 경로는 반복 횟수도 반영합니다.
4. 필요하면 폐촉매 **회수 가치**를 포함하고 계산을 실행합니다.
5. 결과의 납품 기준 촉매 단가, 재료비·가공비·간접비·판매 마진을 확인합니다.
   **출처 근거**에서 각 재료의 가격 기준 시점과 원자료 링크를 볼 수 있습니다.

**일부 미산정** 표시는 단가 자료가 없는 제조 단계가 있다는 뜻입니다.
오토클레이브나 동결건조 등 미산정 공정의 비용은 총액에 들어 있지 않습니다.
카드의 표시만 보고 전체 제조 경로가 모두 계산되었다고 해석하지 마세요.

## 전극 조립체 계산

**전기촉매**를 선택한 뒤 연료전지, 수전해 또는 직접 메탄올 연료전지처럼
응용 분야를 고릅니다. 촉매 분말, 아이오노머, 멤브레인, 기재와 제조 경로를
확인하고, 유효 면적·촉매 담지량·아이오노머/촉매 비율을 입력합니다.

주요 결과는 **유효 면적 cm²당 전극 조립체 원가**입니다. 재료별 내역과
원가 비중도 같은 면적 기준입니다. 별도로 표시되는 촉매 분말의 질량 기준
추정치는 전극 조립체 총액과 구분해서 읽습니다. 제조 시나리오를 적용하면
해당 면적의 장비·인건비·시설 비용이 추가됩니다.

기본 재료는 응용 분야와 제조 경로에 따라 정해집니다. 구체적인 선택 순서와
현재 규칙의 한계는 [전극 재료 기본값 표](audit/electrode-defaults-2026-09-06.md)에
정리되어 있습니다.

## 가격 기준과 출처 확인

**가격 기준**은 앱 전체의 계산과 벤치마크 비교에 적용됩니다.

- **실무 기준**: 실시간 시세를 우선 사용합니다. 저장된 시세가 없으면
  지수 보정 가격이나 기준 가격이 적용될 수 있으므로 출처를 확인합니다.
- **학술 기준**: IMF PCPS와 Johnson Matthey의 저장된 월평균을 사용합니다.
  월평균은 최근 발표 월인지로 판단하며, 실시간 시세의 날짜 규칙을 적용하지
  않습니다. 월별 시계열이 없는 금속은 출처가 표시된 기준 가격을 유지합니다.

담체는 학술 기준에서 UN Comtrade 수입 단가 시계열에 연결될 수 있습니다.
자료가 없으면 라이브러리 가격을 유지합니다. 수입 단가는 여러 등급이 섞인
시장 수준의 지표이므로 촉매용 고순도 제품 견적과 같지 않습니다.

## 비교와 추정 범위

**문헌 벤치마크**에서는 같은 반응군의 촉매 후보를 비교하고 계산기로
불러올 수 있습니다. 경제성·출처 근거·제조 경로·성능의 가중치를 바꾸면
순위도 달라질 수 있습니다. 후보의 문헌 요약과 가격 기준을 함께 확인합니다.

**추정 범위**에서는 현재 조성에 가격·생산 규모의 변동 폭을 적용해
몬테카를로 계산을 실행합니다. 같은 조건이라도 시드를 지정하지 않은 실행은
조금씩 다른 표본을 사용합니다. API에서는 `seed`를 지정해 결과를 재현할 수
있으며, 논문 재현 명령은 [방법론](methodology.md)에 정리되어 있습니다.

환경 영향 결과의 **반영률**은 전과정평가 계수가 연결된 질량 비율입니다.
탄소·실리카·제올라이트처럼 계수가 없는 재료는 자료 공백으로 남습니다.
낮은 반영률을 낮은 환경 영향으로 해석하지 않습니다.

## 실제 생산 조건과 원료 투입량 반영

열촉매의 **제조 단계**에서 실효 생산 속도와 그 근거를 선택적으로 입력할 수
있습니다. 단위는 하루당 미국 톤(short ton)이며, 생산 기간에는 기존 세척
시간이 포함됩니다. 값을 비워 두면 생산 규모별 기본 속도를 사용합니다.
이 입력은 전극 조립체의 면적당 생산 속도를 뜻하지 않습니다.

조성 입력에서 전구체의 실제 투입량을 계산하려면 구매하는 전구체 이름,
순수 전구체 중 최종 성분의 질량 비율, 순도, 수율, kg당 구매 단가와 근거를
입력합니다. 앱은 이 값으로 최종 촉매 1 kg에 필요한 전구체 구매량을 구합니다.
전구체의 불순물을 성분 비율과 순도에서 두 번 차감하지 않도록 주의합니다.
전구체 투입량을 쓰는 항목에는 기존 전구체 가산계수를 중복 적용하지 않습니다.

용매·세척액 등은 **최종 촉매 1 kg당 순구매량**과 kg당 단가, 근거를 별도로
입력합니다. 회수·재사용량을 이미 뺀 투입량이면 근거 메모에 적습니다. 앱이
용매 회수율이나 폐수 처리비를 임의로 더하지 않습니다. 새 값을 입력하지
않은 항목은 기존 계산을 유지합니다.

결과에서 구매 전구체 비용과 원래 성분의 기준 가격을 구분해 확인합니다.
기준 가격은 회수 가치 계산 등에 남지만, 전구체 비용에 다시 더해지지 않습니다.
이 입력으로 환경 영향 자료까지 완성되지는 않습니다. 전과정평가는 기존의
최종 조성과 공정 에너지 가정을 유지하므로 전구체·용매·수율 손실의 누락
범위를 함께 읽어야 합니다.

## 저장된 계산을 같은 조건으로 비교

1. 비교할 조성과 제조법으로 계산한 뒤 결과 화면에서 이름을 붙여 저장합니다.
2. 계산기의 저장된 계산 영역에서 **저장된 계산 비교**를 엽니다. 같은 촉매
   분야와 응용 분야의 계산을 2~4개 선택합니다.
3. **공통 조건의 기준 계산**과 공통 생산량을 선택합니다. 가격 기준은 현재
   앱의 실무 기준 또는 학술 기준을 따릅니다. 화면에 표시되는 기준 연도,
   간접비, 회수 가치와 생산 속도를 확인합니다.
4. **공통 조건으로 비교**를 실행합니다. 표는 저장 당시 결과, 공통 가격을
   적용한 기존 조건의 결과, 가격과 운전 조건을 모두 맞춘 결과를 구분합니다.
5. 각 계산의 **산정 범위와 주의 사항**, **공통 적용 가격과 근거**를 펼쳐
   미산정 공정, 장비 치환, 가격을 가져온 계산과 치환된 가격을 확인합니다.

같은 재료의 직접 입력 가격이 서로 다르면 기준 계산의 가격을 적용합니다.
기준 계산에 없는 재료는 선택한 계산 중 가장 낮은 ID에서 가격을 가져옵니다.
같은 이름이라도 라이브러리 항목이나 품질 등급이 다르면 하나의 가격으로
합치지 않습니다. 전구체와 소모품은 이름에 등급이 구분되도록 적어 주세요.

조성·수율·원료 투입량·제조 경로는 각 계산의 값을 유지합니다. 결과 차이가
모두 제조법 때문이라고 해석하면 안 됩니다. 예전 저장 결과와 재계산 결과의
차이에는 계산 모델의 변경도 포함될 수 있습니다. 전극끼리 비교하면 유효
면적·도포량·이오노머 비율·제조 조건도 맞추며, 비교 단가는 cm²당 전극 조립체
원가입니다. 원래 저장된 계산은 비교 실행으로 바뀌지 않습니다.

## 구매 근거와 실제 비용 기록

직접 입력한 재료 가격에는 **구매 근거**를 펼쳐 공급사, 견적일, 구매량과
단위, 품질 등급, 가격에 포함된 비용, 문서 위치 또는 출처 URL을 기록할 수
있습니다. 이 정보는 계산과 함께 로컬에 저장되며, 앱이 공급사를 검증했다는
뜻은 아닙니다.

실제 비용을 대조하려면 계산을 저장한 뒤 실제 비용 기록 영역에 자료의
가격·단위·날짜·출처를 입력합니다. 원재료 구매 가격인지, 판매 마진 전 제조
원가인지, 판매 마진을 포함한 납품 단가인지, 회수 가치를 차감한 단가인지를
구분합니다. 실제 조성·등급·생산량·생산 속도·제조 단계와 포함 비용은 원자료를
읽고 별도로 입력합니다. 저장된 가정을 실측값인 것처럼 복사하지 마세요.

비교 조건이 갖춰진 열촉매의 질량 기준 실적만 오차 계산에 포함됩니다.
조건이 없거나 다르면 제외 이유를 표시하고 오차를 비워 둡니다. 공급사 견적,
미산정 공정이 있는 계산, 실제 전구체·소모품 투입량을 대조하지 못한 계산,
전극의 면적 기준 기록도 보관할 수 있지만 현재의 오차 평균에는 넣지 않습니다.
비교 가능한 실적이 없으면 MAPE는 표시하지 않습니다. 사용자가 확인한 로컬
실적의 비교 결과를 COMET 전체의 독립 검증 정확도로 해석하지 않습니다.
