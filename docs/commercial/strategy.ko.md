# COMET 연구·공개 개발·구독 사업화 준비

2026-09-07 작성. 계약 체결, 판매 개시 또는 투고 완료를 의미하지 않는다.

공개 연구용 COMET은 현행 PolyForm Noncommercial 1.0.0을 유지한다. 회사는 권리자로부터 별도의 상업 이용·배포·서비스 제공 권한을 확보한 뒤 조직 단위 구독을 판매하는 구조를 준비한다. 공개 저장소의 존재만으로 회사에 판매 권한이 생기지는 않는다. 현재 데이터 권리와 권리자 확인이 끝나지 않았으므로 판매 가능한 상태로 표시하지 않는다.

## 세 목표를 연결하는 방법

| 목표 | 남겨야 할 결과 | 완료를 판정하는 증거 |
|---|---|---|
| 논문 | 가격·생산 규모·제조 경로가 의사결정에 미치는 영향을 분리한 연구, 재현 코드와 입력 | 수치와 산출 파일의 대응, 독립 검증의 범위, 실제 저자 승인, 투고·심사 결과 |
| 개인 포트폴리오 | 설치 가능한 공개 프로젝트, 설계·검증 설명, 본인의 확인된 기여 | 커밋·PR·실행 기록, 정확한 저자·기여 표기; 별·다운로드 수를 성과처럼 지어내지 않음 |
| 회사 상품 | 조직별 자료 격리, 구독 권한, 관리·지원·내보내기, 계약·운영 체계 | 두 조직 간 접근 차단, 만료·해지 처리, 복구 시험, 데이터 재사용 권리, 회사의 실제 승인 |

연구용 계산식에 임의의 제한을 넣어 유료판 구매를 강제하지 않는다. 구독 가치는 조직 자료 관리, 공동 작업, 검증된 자료 갱신, 관리형 실행과 지원에 둔다. 초기 상품은 수동으로 계약·조직을 개설하는 B2B 구독으로 준비한다. 이는 가격과 결제 업체가 확정되지 않은 상태에서 실제 결제 연동을 만들어 내지 않기 위한 가정이다. 월·연 구독 가격, 좌석 수와 SLA는 고객 수요와 운영비를 확인한 뒤 주문서에서 정한다.

## 권리 구조

[PolyForm 원문](https://polyformproject.org/licenses/noncommercial/1.0.0)은 비상업적 목적의 이용을 허용하며, 권리자가 다른 상대에게 별도 라이선스를 부여하는 것을 막지 않는다. 기존 라이선스 수령자에게 부여된 권한이 회사 계약으로 자동 취소되는 것은 아니다. 제안 구조는 권리자의 별도 상업 이용 허락이며, 저작권 전부 양도를 기본값으로 삼지 않는다.

다만 실제 권리자가 누구인지는 확인해야 한다. [저작권법 제9조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1024713185)는 업무상 저작물의 저작자와 프로그램에 관한 예외를 정한다. 학생·연구원 신분만으로 개인 소유 또는 대학 소유라고 단정할 수 없다. 고용계약, 연구비 협약, 산학협력단 규정, 공동 개발 기여와 기존 계약을 검토할 자료로 남긴다. 아래 계약 초안은 그 확인과 전문가 검토를 위한 문서다.

## 출시 전 실제 결정을 필요로 하는 사항

| 항목 | 현재 상태 | 확정할 주체 |
|---|---|---|
| 코드 권리자, 대학·연구비 관련 권한 | 확인 못 함 | 개발자·대학/산학협력단·관련 계약 당사자 |
| 판매 회사의 법인명·등록 정보·담당자 | 확인 못 함 | 교수님 회사 |
| 별도 상업 라이선스와 외부 기여자 동의 | 미체결 | 실제 권리자와 회사, 필요한 기여자 |
| 가격·문헌·워크북 유래 데이터의 상업 이용·재배포 | 검토 중, 미승인 자료 있음 | 출처별 권한 검토 담당자 |
| 구독 가격·기간·환불·세금·SLA | 미정 | 회사 |
| 호스팅 국가·개인정보 처리자·결제 처리 업체 | 미정 | 회사와 운영 담당자 |
| 논문 저자·이해상충·연구비·투고 저널 | 실제 승인 전 | 연구자와 책임저자 |

실제 고객 자료, 참가자 개인정보, 계약 서명, 결제 비밀값은 공개 저장소에 넣지 않는다. 이 준비 작업에서는 외부 계정·API 키를 발급하거나 결제를 실행하지 않는다.
