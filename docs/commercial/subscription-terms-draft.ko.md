# B2B 구독 주문서·운영 조건 검토 초안

상태: **미체결·판매 미개시**. 회사의 실제 계약·개인정보·세무 검토를 위한 초안이며 고객에게 현재 제공되는 약관이 아니다.

## 주문서에서 확정할 사항

판매 회사와 구매 조직의 법적 명칭, 사업자 정보, 담당자, 상품 범위, 허용 좌석 수, 시작·종료일, 통화·가격·부가세, 청구 주기, 결제 방식, 갱신 통지, 해지·환불 기준을 기입한다. 현재 값은 전부 미정이다. 실제 결제 업체를 선정하기 전에는 카드 정보나 결제 비밀값을 수집하지 않는다.

## 서비스와 자료

COMET은 입력한 조성·제조 단계·생산 조건과 출처가 명시된 가격 가정으로 초기 제조 원가를 추정한다. 고객의 실제 구매 견적, 공급 보장 또는 확정 수익을 제공하는 계약으로 표현하지 않는다. LCA 반영 범위와 미산정 공정, 문헌 후보의 가정은 결과와 함께 제공한다. 독립 검증 전에는 실제 공장 원가에 대한 정확도 보증을 판매 문구에 넣지 않는다.

고객 조직의 계산·견적·관측 자료에 대한 권한은 고객에게 유지한다. 회사는 계약한 서비스 제공·복구에 필요한 범위만 처리한다. 자료를 논문·사례 홍보·학습에 재사용하려면 별도 명시적 동의를 받아야 한다. 로그에는 조성, 원가, 암호, 세션 또는 결제 비밀값을 남기지 않는다. 조직 간 자료 공유는 기본 비허용이다.

## 접근과 구독 종료

서버가 조직·좌석·구독 유효 상태를 판정한다. 고객이 브라우저의 화면이나 요청 값을 바꿔 구독 권한을 얻을 수 없어야 한다. 일반 구독 만료·해지로 신규 계산이 제한되더라도 보존 기간 내 기존 자료의 조회·내보내기는 제공하는 정책으로 준비한다. 보안상 계정 정지는 일반 구독 만료와 구분하고 안전한 별도 반환 절차를 둔다. 보존 기간과 삭제 일정은 계약·법적 의무를 검토해 확정하며, 임의의 기간을 현재 약속하지 않는다.

## 운영 약정

가동률 목표, 지원 시간·응답 목표, 장애 통지, 유지보수 창, 백업 간격·보존 기간, 복구 목표, 데이터 저장 국가, 수탁자·재수탁자, 사고 대응 담당자는 운영 시험과 회사 승인 후 별첨으로 확정한다. 구현 시험 결과를 실제 유료 서비스의 SLA 달성 기록으로 표현하지 않는다.

자동 갱신·철회·환불·세금·소비자/사업자 구분·개인정보 고지의 적용은 실제 거래 형태와 관할에 따라 검토한다. 이 초안은 계약상 책임 제한이나 개인정보 처리의 적법성을 보증하지 않는다.
