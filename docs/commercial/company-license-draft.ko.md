# 회사 사업화 이용허락 검토 초안

상태: **미체결 초안**. 이 문서는 권한을 부여하지 않는다. 당사자와 권리 범위를 확인하고 법률·산학협력 검토를 거쳐 별도 서명해야 한다. 기존 LICENSE를 대체하지 않는다.

| 계약 항목 | 검토할 내용 |
|---|---|
| 허락자 | 실제 권리자 법적 명칭·주소·권한 증빙: 미확정 |
| 이용자 | 교수님 회사 법인명·등록 정보·주소·담당자: 미확정 |
| 대상 | COMET의 명시된 버전/커밋, 코드·문서 목록과 제외 자료 별첨 |
| 권한 | 회사의 구독 서비스 운영, 고객에 대한 명시 범위의 상업 이용 허락, 필요한 실행 파일 배포와 유지보수 변경 |
| 독점 여부 | 비독점 제안. 독점·지역·업종 제한은 별도 협상 전까지 부여하지 않음 |
| 기간·지역·대가 | 모두 미확정. 자동으로 영구·전세계·무상 권한을 부여하지 않음 |
| 외부 데이터·의존성 | 출처별 별도 조건을 따름. 회사에 허락할 수 없는 권한은 대상에서 제외 |
| 개선 결과 | 기존 코드와 이후 회사·개발자 개선분의 소유·역라이선스·유지보수 책임을 구분해 별첨 |
| 연구·경력 기록 | 확인된 개발 기여와 인용 표기 유지. 논문 발표와 개인 포트폴리오 이용 범위·비밀정보 검토 기간을 합의 |
| 종료 | 신규 서비스 제공·배포 중지 범위와 기존 고객 계약 이행, 자료 반환·내보내기, 보존 의무를 명시 |
| 책임·분쟁 | 현지 법률에 맞는 책임 한도·보증·준거법·분쟁 절차는 전문가 검토 후 확정 |

서명 전 확인 자료:

1. 고용·용역·연구비·대학 지식재산 규정 및 기존 이용허락 계약.
2. 버전별 기여자 목록과 상업 이용에 필요한 실제 허락. PR 제출 당시의 비상업 라이선스 동의만으로 과거 기여자의 상업 이용 동의를 소급 가정하지 않는다.
3. 출처별 데이터 권리 검토표와 배포물의 제3자 고지. CatCost 워크북에서 추출했다고 명시된 기존 데이터는 독립 수집 근거 또는 권한 확인 전 승인하지 않는다.
4. 회사가 제공할 지원·보안·자료 처리 범위와 연구 결과의 공개 범위.

권리자의 상업 이용 허락, 논문 저자 자격, 회사 매출 배분은 서로 다른 합의 대상이다. 저장소 이름이나 커밋 수만으로 저자 순서·소유 지분·수익 배분을 정하지 않는다. 확정 전에는 서명란이나 확정 금액을 채우지 않는다.
