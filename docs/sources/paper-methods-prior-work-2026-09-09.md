# COMET 방법론의 선행연구 대조 — 2026-09-09

촉매 원가·실험 합성·수명·다기준 순위와 관련된 **8개 1차 연구/도구를 선정해 대조**했다. 체계적 문헌고찰이나 세계 최초 여부의 전수 검증은 아니다. 검색어는 `catalyst synthesis manufacturing cost experimental cost lifetime`, `catalyst selection multicriteria decision normalization rank reversal`, 해당 논문 제목과 DOI였다. 유료 접근·자료 구매·계정 발급은 없었다.

## 확인한 중복과 COMET의 주장 범위

| 선행연구 | 실제로 확인한 내용 | COMET에서 구분할 기여 |
|---|---|---|
| [Baddour et al., 2018](https://doi.org/10.1021/acs.oprd.8b00245) | 재료·제조 단계 기반 촉매 단가 추정 | 채택한 식·단가의 저작성을 주장하지 않는다. COMET의 입력 추적과 비교 절차를 구분한다. |
| [Van Allsburg et al., 2022](https://www.nature.com/articles/s41929-022-00759-6) | 원가·환경 평가, 규모·제조 조건과 촉매 대안의 비교 | TEA/LCA 통합, 규모 효과와 민감도 분석 자체를 새 발명으로 소개하지 않는다. |
| [BioSTEAM 연구](https://doi.org/10.1021/acssuschemeng.9b07040), [공식 문서](https://biosteam.readthedocs.io/en/latest/) | 공정 모사와 경제성·환경·불확실성 분석 | COMET의 촉매 자료·기능 단위·추천 진단에 맞춘 구현을 설명한다. |
| [Gkika and Kyzas, 2025](https://doi.org/10.1021/acssuschemeng.5c06752) | 산화물 합성의 활동기준 원가·총소유비용 분석 | 수율과 합성 비용의 연결 자체가 최초라는 주장을 배제한다. |
| [Ferdous et al., 2025](https://doi.org/10.1039/d5cy00189g) | Pt/STO의 CatCost·GREET 기반 분석 | 동일한 원가 방법을 사용한 별도 논문을 독립 실측 정확도 검증으로 세지 않는다. |
| [Petel et al., 2024](https://doi.org/10.1002/adsu.202300030) | Ni 나노입자 합성의 실험 수율과 원가 추정을 연결 | 원가를 이용한 실험 개선의 선례다. 이번 SI는 공개 수율의 역수 효과를 설명하며 COMET의 산업 오차로 해석하지 않는다. |
| [Mohammadi and Rezaei, 2023](https://doi.org/10.1002/mcda.1806) | 정규화·가중합의 순위 역전 문제와 별도 대안 방법 | 순위 역전 현상은 알려져 있다. COMET의 후보군에서 영향과 고정 기준 대조를 재현한 것이 이 연구의 분석 범위다. 해당 논문의 새 순위 방법을 도입하지 않았다. |
| [Mendoza Suarez and Tatarchuk, 2025](https://doi.org/10.1007/s41981-024-00342-z) | 가정한 촉매 수명이 회분식·연속 공정 경제성에 미치는 영향 | 제조 단가만으로 수명당 생산성을 주장할 수 없다. 이 논문의 가정값을 COMET 후보의 측정 수명으로 옮기지 않았다. |

선행 도구에서 특정 기능을 확인하지 못했다는 이유로 “없다”고 표시하지 않았다. 현재 주장할 수 있는 기여는 가격·근거 상태, 제조 경계, 비교 단위와 추천 가정을 함께 추적하는 명시적 절차 및 그 절차로 수행한 통제·공동 민감도 분석이다. 실제 선택의 개선이나 산업 정확도 우위는 별도 실증을 요한다.

## 접근과 외부 근거

[접근 기록](paper-methods-access-2026-09-09.json)에 DOI별 Crossref 응답, 제목·저자·발표 정보, 실제 HTTP 상태·최종 URL·응답 해시를 남겼다. 처음 일부 Crossref 요청은 429였으며 순차 재시도에서 모두 200을 받았다. 직접 요청의 200 응답 중 인증 확인 HTML도 있으므로 본문 접근 성공과 구분했다. CatCost·산화물·순위·수명 논문은 웹 판독기의 공개 출판사 본문/색인과 함께 검토했다. BioSTEAM 공식 문서와 두 DOE/NLR PDF는 직접 수신했다.

Petel 논문의 Table 1은 PDF 3쪽을 렌더링해 숫자·열·각주를 확인했다. 수율은 ICP-OES 실험값이고 비용은 논문의 모델 결과다. DOI의 온라인 발표는 2023년이며, 권·논문번호와 PDF의 지면 연도는 2024년이다. 가격 기준 연도는 PDF 6쪽에서 확인했다. 전체 PDF·스크린샷·개별 전구체 가격은 제품 데이터에 넣지 않았다.

[추출 근거](paper-methods-evidence-2026-09-09.json)와 [추가 재현 결과](../paper/methods-2026-09-09/methods_study.json)는 서로 다른 근거를 섞지 않는다. 새로 적격 판정된 산업 전체 원가 관측은 **0건**이며, 외부 연구자 참여 결과도 **0건**이다. 제조원가 MAPE를 만들거나, 공개 가격을 실측 납품 원가로 대체하지 않았다.

## 다음 실증에서 필요한 대응 조건

제조 비용은 조성·원료 등급·제조 단계·수율·생산량·기준 시점·포함 비용을 함께 기록해야 한다. 촉매의 실제 선택 개선은 같은 반응 조건의 활성·선택도·누적 생성물·수명까지 대응시켜야 한다. 서로 다른 문헌의 원가와 최고 성능을 임의로 결합하지 않는다. 실제 참여자 평가와 회사 자료 제공은 아직 수행되지 않았으며, 기존 [수집 양식](../research/actual-cost-collection.ko.md)을 유지한다.
