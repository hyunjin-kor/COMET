# 실제 원가 자료 수집 양식

현재 확보한 독립 실측 검증 자료는 0건이다. 아래는 향후 자발적으로 제공받을 자료의 빈 양식이며, 거래나 제조 기록이 아니다. 무료로 제공 가능한 자료만 받는다. 원본 견적서·거래처명·회사 조성은 공개 저장소에 올리지 않는다.

기관이 승인한 비공개 저장 위치에 사본을 만들고 다음 항목을 채운다. 공개용 결과에는 익명 식별자와 공개 허락을 받은 조건·집계치만 사용한다. `verified_by_user=true`는 사용자의 확인 표시이며 제3자 감사나 출판 허락을 뜻하지 않는다.

| 항목 | 제공자가 기입할 내용 |
|---|---|
| 익명 자료 식별자 | 개인·거래처 정보가 없는 식별자 |
| 자료 종류 | 공급사 견적 / 세금·상업 송장 / 실제 제조 기록 / 공개 문헌 |
| 이용 허락 | 내부 분석 가능 여부, 논문 공개 가능 항목, 상품 데이터로 재사용 가능 여부를 각각 확인 |
| 촉매 | 정확한 조성 질량분율, 담체·등급, 건조/습윤·용액 상태 |
| 금액·단위 | 실제 값, 통화, kg/lb 또는 면적 단위; 근거 없는 환율 환산 금지 |
| 날짜 | 견적/거래/제조일과 가격 기준 기간 |
| 규모 | 구매 포장 질량과 제조 캠페인 질량을 구분; ton은 short ton인지 metric tonne인지 명시 |
| 제조 조건 | 제조 단계, COMET template_id, 생산량/일, 가동 시간, 수율, 미산정 공정 |
| 원가 범위 | 재료 구매비 / 제조원가 / 납품 기준 촉매 단가 / 회수 가치 차감 후 단가 |
| 포함·제외 | 인건비·간접비·마진·세금·운송·용제·폐기물·회수 가치·전극 조립체 포함 여부 |
| 증빙 | 비공개 원본 경로와 파일 해시, 확인 담당자 및 확인 날짜 |
| 불확실성 | 추정값·누락 항목과 실제 측정값을 구분 |

앱의 실제 비용 관측 입력은 `backend/schemas/cost_evidence.py::ActualCostObservation`에 대응한다. 빈 값은 관측값으로 저장하지 않는다. 실제 데이터가 생기면 모델 입력과 비교 대상 가격을 먼저 고정하고, 조성·규모·날짜/통화·제조 경로/수율·원가 범위가 모두 맞는 경우에만 동일 조건 오차를 계산한다. 비교 대상 금액을 보고 모델 입력을 맞추지 않는다.

조건이 다른 자료는 참고 사례로 남긴다. 누락을 0으로 치환하거나 소량 판매가를 대량 제조원가로 간주하지 않는다. 보고에는 전체 수집 건수, 제외 이유별 건수, 최종 일치 건수, 관측별 잔차를 함께 제시한다. 동일 공장의 반복 자료는 서로 독립적인 공장 표본으로 세지 않는다. 논문 공개 여부와 회사의 데이터 재사용 허락은 실제 권리자가 결정해야 한다.
