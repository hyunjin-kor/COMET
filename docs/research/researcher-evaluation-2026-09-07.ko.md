# 외부 촉매 연구자 사용 평가 계획

상태: **실제 참여자 0명, 관측 결과 없음**. 아래는 실행 가능한 평가 계획이다. 자동 브라우저 검사와 개발자의 확인은 외부 사용자 실험으로 세지 않는다. 모집·동의·기관 검토가 필요한 부분은 아직 수행하지 않았다.

진행자가 실제 사용자의 과업 수행을 관찰하고 생각을 말하도록 요청하는 방식은 [GOV.UK의 진행자 동반 사용성 평가 안내](https://www.gov.uk/service-manual/user-research/using-moderated-usability-testing)를 참고했다. 아래 과업·목표·판정 기준은 COMET 팀의 제안이며, 표준 인증이나 검증된 심리 측정 척도가 아니다.

## 대상과 준비

첫 라운드의 제안 목표는 촉매 연구자 6명이다. 열촉매와 전기촉매 사용자, 초기 사용자와 원가 분석 경험자를 포함한다. 이는 질적 문제 발견을 위한 편의 표본 목표이며 통계적 검정력이나 전체 연구자 대표성을 주장하지 않는다. 다른 기관의 참여가 가능한지 확인하되 자발적 참여로 진행하고, 지도·고용 관계가 참여에 영향을 주지 않도록 한다.

기관의 연구윤리·개인정보 절차 적용 여부를 실제 담당자가 확인한 뒤 모집한다. 연구 목적, 수집 항목, 보관 기간·삭제 시점, 공개 범위, 중단·철회 방법과 담당 연락처를 확정한 동의문을 사용한다. 이 계획 자체를 동의서로 간주하지 않는다. 연락처와 관측 자료의 연결표는 별도로 보관한다. 녹화는 별도 동의가 있을 때만 한다. 고객 데이터 대신 공개 가능한 시나리오를 사용한다.

평가 전에 앱 커밋·버전·실행 환경·화면 크기·언어·가격 스냅샷 해시와 시드를 고정한다. 한 라운드 중에는 앱이나 가격 입력을 바꾸지 않는다. 개발자 예행연습은 본 표본에서 제외한다. 각 참여자는 익명 ID만 사용하고 사전 설명은 동일하게 제공한다. 예상 세션 길이는 45분이며 필요하면 휴식·중단할 수 있다.

## 과업과 성공 판정

| ID | 참여자에게 줄 과업 | 진행자 확인 기준 |
|---|---|---|
| U01 | 열촉매 조성·생산 규모를 입력하고 제조법을 선택한 뒤 결과를 저장한다. | 지정 조건의 저장 결과와 제조 경로가 맞고 단가 단위를 설명함 |
| U02 | 선택한 제조법을 해제했다가 다시 선택하고 다른 제조법과 비교한다. | 선택 상태·단계·결과 라벨이 일관되고 원치 않는 입력 손실이 없음 |
| U03 | reference와 live 기준을 바꾸고 시세 기준과 출처를 찾아 설명한다. | 월평균/현재 수집값과 기준 기간 차이를 구분하고 오래된 값을 실시간으로 오해하지 않음 |
| U04 | 고정 시드로 추정 범위를 확인하고 결과를 해석한다. | 범위를 모델 가정의 결과로 설명하고 실제 오차 보장으로 오해하지 않음 |
| U05 | 전기촉매 면적·담지량을 입력하고 전극 조립체 내역을 확인한다. | 면적 단가와 분말 질량 단가를 구분하고 포함 재료·제외 공정을 설명함 |
| U06 | 두 저장 결과를 비교하고 근거·가정을 포함해 내보낸다. | 지정 두 결과를 정확히 비교하고 파일을 다시 열어 조건·단위·출처를 찾음 |

U01→U02와 U05는 관련 과업으로 유지한다. 열촉매·전기촉매 블록의 시작 순서는 참여자별로 번갈아 배정하고 실제 순서를 기록한다. 경험이 없는 분야의 과업도 설명을 강요하지 않고 경험 부족·도움 요청을 별도 기록한다. 모든 과업에 동일한 중단 시간 제안(8분)을 적용하고 중단·미실시를 성공으로 처리하지 않는다.

## 기록과 분석

빈 [CSV 양식](researcher-evaluation-observations.csv)에 참여자×과업 한 행을 기록한다. 시작은 과업 설명을 마친 시점, 종료는 제출·포기·시간 제한 시점이다. `outcome`은 independent/assisted/failed/not_attempted, `comprehension`은 correct/partial/incorrect/not_assessed로 기록한다. 도움 횟수, 실제 경과 시간, 잘못된 저장·조성·단위·해석, 불편 원인을 함께 적는다. 인용은 공개 동의가 있을 때만 익명으로 사용한다. 실제 기록 CSV는 공개 저장소에 저장하지 않는다.

성공 비율은 분자/분모를 함께 쓰고 미실시를 구분한다. 완료 시간은 독립 완료와 도움받은 완료를 나눠 중앙값·범위를 제시하고, 실패한 사람을 시간 분석에서 제외한 사실을 밝힌다. 소표본 결과로 모집단 우월성·인과효과·의학적/안전 성능을 주장하지 않는다. 기존 도구 대비 시간 단축은 같은 조건의 비교 실험을 별도로 하지 않으면 주장하지 않는다.

수정 우선순위는 잘못된 조성·단위·내역을 믿게 만드는 오류, 저장 결과 손실/혼동, 과업을 끝내지 못하는 흐름, 그 밖의 표현·배치 순이다. 릴리스 전 해결 기준은 첫 두 유형의 미해결 오류 0건으로 제안한다. 해당 기준 충족은 실제 사용 관측과 재검사로 판단하며 자동 검사만으로 외부 사용성 검증 완료라고 쓰지 않는다. 다음 라운드는 수정 버전과 변경점을 기록하고 첫 라운드와 구분한다.
