# COMET 프로젝트 포트폴리오

COMET은 촉매 조성·제조 경로·생산 조건을 원가와 출처 근거로 연결하는 연구용 소프트웨어다. 열촉매는 질량 기준 제조 원가를, 전기촉매는 면적 기준 재료 조립체 원가를 다룬다. 가격 기준과 계산 범위를 드러내고 같은 입력을 재현하는 데 초점을 둔다.

2026-09-07 기준 준비 소스는 1.4.0, 실제 공개 릴리스는 v1.3.24다. 논문과 회사 구독 서비스는 준비 단계이며, 게재·매출·실제 고객 수를 성과로 주장하지 않는다.

## 검증 수준

현재 원고 갱신 시점의 백엔드 테스트는 **856개 통과**했다([출력](audit/commercial-c11-pytest-2026-09-07.log)). 계정 분리·만료·자료 복구는 자동 시험과 합성 계정의 실제 브라우저 실행으로 확인했다. 이는 외부 연구자 평가나 인터넷 운영 보안 인증을 대신하지 않는다.

CatCost Table 6.2의 Pt/C는 센트 단위로 일치한다. Ni/Al₂O₃는 −6.65%, FCC는 각주 b 생산 속도에서 +1.16% 차이를 보이며 원인은 [방법론](methodology.md)에 공개한다. 이 검증은 발표된 방법을 재현하는 수준이다. 조건이 맞는 독립 제조 원가 실측 자료는 아직 없어 경험적 예측 오차를 제시하지 않는다.

현재 기술은 React 19·TypeScript·Vite, FastAPI·SQLModel·SQLite, Electron·PyInstaller다. 공개 코드는 PolyForm Noncommercial 1.0.0이며 OSI 승인 오픈소스로 소개하지 않는다. 문헌 방법론의 원저자와 데이터 제공자의 기여는 별도로 인용한다.

## 기여와 이력 표기

저장소의 기존 인용 메타데이터에는 Hyunjin Kang이 기재되어 있다. 사용자에게서 확인된 역할은 프로젝트 목표·제품 요구·연구 방향의 제시와 공개 저장소 운영이다. 이 페이지는 미확인 단독 저작권, 회사 또는 대학의 권리 포기, 공동저자의 동의를 증명하지 않는다.

코드·시험·문서 작성에 Codex의 지원을 사용했다. 실제 연구자 기여, 검토 책임과 최종 저자 순서는 [저자 확인표](paper/author-readiness-2026-09-07.ko.md)에서 확정한다. 커밋 작성자만으로 연구 기여 전체를 추정하지 않는다.

이력서에는 확인 가능한 범위로 다음과 같이 설명할 수 있다.

> 촉매 제조 원가 추정을 위한 COMET 프로젝트를 기획하고 연구·제품 요구를 정의했다. 시세와 월평균 기준, 제조 경로별 원가, 문헌 비교 및 재현 분석을 통합한 Windows 소프트웨어를 AI 코딩 도구의 지원으로 개발했다. 방법 재현·자동 시험·실제 화면 기록을 공개하고 논문화와 회사 구독 서비스의 권리·운영 준비를 진행하고 있다.

실제 논문 게재, 외부 사용자 평가와 회사 매출은 근거가 생긴 뒤 별도로 추가한다. 저장소의 존재나 테스트 수를 저널 채택, 산업 정확도 또는 상업 이용 허락으로 해석하지 않는다.

- 회사 상품: 실제 권리자·기관·회사 간 허락을 확정하고, [사업화 계획](commercial/strategy.ko.md)의 가격·계약·운영 조건을 결정한다. 현재 기록은 체결된 계약이 아니다.
