## 가정과 확인하지 못한 사항

- “전수”는 현재 제품·문서·논문의 설명 전체와 모든 관련 문자열의 처리 근거를 뜻한다. 과거 실행 기록이나 실제 데이터 출처를 현재 홍보 문구로 덮어쓰는 것으로 해석하지 않았다.
- 선행연구에서 채택한 원가 식과 단가는 계속 인용한다. 소프트웨어 독립 개발은 모든 데이터의 독립 수집·상업 재사용 허락을 뜻하지 않는다. 기존 권리 검토와 외부 실증 부족은 그대로 남는다.
- 두 핵심 논문은 Crossref HTTP 200으로 제목·DOI를 재확인했다. ACS 출판사 페이지는 HTTP 403이었다. Nature는 웹 도구의 인증 리다이렉트 실패와 별도로 직접 HTTP 200 응답을 받았으며, BioSTEAM 공식 문서는 HTTP 200과 본문을 확인했다. [접근 기록](../sources/positioning-prior-work-2026-09-08.json)에 도구별 차이를 남겼다. 유료 자료는 사용하지 않았다.
- 인앱 브라우저의 전체 페이지 캡처 한 차례가 실패하여 지원되는 화면 캡처로 저장했다. 일부 DOM 선택자는 접근성 역할과 달라 실패한 뒤 현재 트리의 요소로 재선택했다. 실제 화면 확인은 성공했고, 계산·lint·build·pytest 진실 신호의 연속 실패는 없었다.
- 네이티브 OS 정보 창은 화면을 직접 열어 확인하지 못했다. 코드 계약 검사와 패키징·데스크톱 스모크를 구분하여 기록한다. 이 계약 검사는 `scripts/test_desktop_about.mjs`로 저장하고 프론트 CI에 연결했다.
- 패키지 1.4.0은 준비 버전이다. `gh release list -L 1`로 재확인한 공개 최신 버전은 v1.3.24이며, 이 실행은 설치된 사용자 앱이나 GitHub 기본 브랜치를 교체하지 않는다. 외부 서비스·태그·릴리스를 게시하지 않는다.
