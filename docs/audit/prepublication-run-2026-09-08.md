## 가정·확인 못 한 것

현재 기능에서 재현되는 결함을 고쳤다. 발견하지 못한 결함이 전혀 없다는 보증이나 상용 서비스 용량·보안 인증을 주장하지 않는다. 실제 대규모 부하 시험은 하지 않았고 이번 실행의 시간은 성능 개선 전후 비교로 해석하지 않는다. 유료 자료 구매·유료 API·새 단가 추정 없이 진행했다. LICENSE·원본 데이터·사용자 실제 DB·설치된 앱은 바꾸지 않았다.

기존 C14의 외부 전제는 계속 미해결이다: 회사/코드 권리자 승인, 제3자 데이터의 상업 이용·재배포 권리, 실제 저자와 기여, 일치 조건의 독립 제조원가 관측값과 연구자 사용자 평가, 목표 저널의 실제JCR연도/분야/Q1·IF자격. 무료 열람과 상업 재배포 허가는 별개다. 이 사실을 코드로 해결하거나 없는 관측값으로 채우지 않았다. 기존 목표 저널 표기는 잠정 상태를 유지하며 새 투고 적합성 판정을 내리지 않았다.
