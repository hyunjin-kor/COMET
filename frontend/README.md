# CatTEA Frontend

React/Vite renderer for the CatTEA desktop application.

## Project Links

- Repository: https://github.com/hyunjin-kor/CatTEA
- Latest release: https://github.com/hyunjin-kor/CatTEA/releases/tag/v1.1.13
- Root handoff file for Claude: `../CLAUDE.md`

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

The normal desktop development entry point is the root command:

```bash
npm run dev
```

That starts the FastAPI backend, the Vite renderer, and the Electron shell together.
